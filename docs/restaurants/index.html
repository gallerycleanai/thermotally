Where paper logs go wrong

"Pencil-whipped" logs

A week of identical 38°F readings in the same pen, filled in right before the inspector arrived. Inspectors recognize it, and it doesn't protect you if something goes wrong.

Out-of-range, no action

A 46°F reading is written down, and then nothing happens. The Food Code cares about what you did next: move the food, fix the unit, or discard it.

Cooling is never tracked

The 2-hour/6-hour cooling rule is one of the most-cited problems, because nobody remembers to check the stockpot at the 2-hour mark.

Restaurant FAQ

Which logs does a restaurant need to keep?

It depends on your state and county, but most inspectors expect to see cold and hot holding temperatures, cooling records for food you cool, receiving checks, and a cleaning schedule. If you run a HACCP plan or a variance (for example sous vide or reduced-oxygen packaging), you need its monitoring records too.

How many readings a day is enough?

The FDA Food Code doesn't set a single frequency. Twice a day for storage units is a common minimum. Many operators check hot and cold holding every 2 hours during service so problems can still be fixed in time.

Can several cooks use one account?

Yes. The plan is unlimited staff per location, each logging under their own initials, so the record shows who took each reading.
