Whatever the chart says, the product label is the legal instruction for use, and the Code requires you to follow it. The Code also requires a test kit that measures sanitizer concentration (§4-302.14).

How to use it

  1. Write the product name and the ppm range from its label at the top.
  2. Test each solution when you make it up, and again during the shift. Buckets for wiping cloths lose strength as food soil builds up, so check them every few hours.
  3. Use the strip made for your chemical. Chlorine strips don't read quat, and the reverse.
  4. If the reading is low, remake the solution and write the re-test reading. If it's far too high, dilute it. Strong sanitizer isn't "extra safe"; it can leave residue on food-contact surfaces.

FAQ

How often should I test sanitizer?

The Food Code requires a test kit but doesn't set a frequency. A common routine is every time a solution is made and every 2–4 hours for buckets and sinks in use. Your health department or HACCP plan may set its own.

Can I log the dish machine on the same sheet?

Yes, for chemical (low-temperature) machines. Write "dish machine" in the location column and test the final rinse as the machine's maker describes. High-temperature machines are checked by rinse temperature instead.
